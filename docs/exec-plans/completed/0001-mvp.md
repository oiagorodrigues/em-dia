# 0001: MVP (completed)

## Goal

Ship the first usable version of em dia (then called "ponto."): an employer and a domestic worker can link through an invite, record and confirm days, track extras, register payments with receipts, and read the same monthly summary, on an installable PWA.

## Scope

Specs: [features](../../product-specs/features.md), [api-contract](../../product-specs/api-contract.md), [DESIGN](../../DESIGN.md).

Foundation

- [x] `@emdia/shared`: domain types, schemas, RBAC, pay math, time helpers
- [x] API skeleton: config, db, migrations, logger, error mapping, health
- [x] Web skeleton: router, stores, api client, tokens.css, layout and nav
- [x] Harness: architecture, taste and doc tests in CI

Features

- [x] Auth and RBAC: register, login, refresh rotation, logout, logout-all, forgot and reset password, lockout
- [x] Contracts and invites: create, edit, end, invite code, join
- [x] Time card with dual confirmation: upsert, delete, confirm
- [x] Clock in and out
- [x] Adjustments: bonus, transport, advance, deduction
- [x] Payments, receipts and acknowledgement ("recebi")
- [x] Monthly summary and CSV statement
- [x] Activity log
- [x] Dashboard for both roles
- [x] PWA: install, offline reads, update prompt, manifest screenshots
- [x] Dark mode with manual override
- [x] Worker Pix key and phone shown to the employer
- [x] Refresh reuse grace window
- [x] Production static serving of the web build with a PWA-compatible CSP
- [x] Dockerfile and healthcheck
- [x] Browser e2e tools in `tools/e2e` (screens and 10 journeys)

Hardening

- [ ] [QUALITY_SCORE](../../QUALITY_SCORE.md) at B or better everywhere; remaining gaps listed there and in plan 0002

## Decision log

- 2026-10-06: Use `node:sqlite` instead of a native addon, to avoid build steps. Reason: Node >= 22.18 ships it.
- 2026-10-06: Access token in memory, refresh token in an HttpOnly cookie. Reason: no token reachable from injected script.
- 2026-10-06: Money stored as integer cents. Reason: exact sums, no float rounding.
- 2026-10-06: Return 404 for resources the caller cannot see. Reason: do not leak existence.
- 2026-10-06: Offline writes are not queued in the MVP. Reason: server time is authoritative for the clock and conflicts need dual confirmation design.
- 2026-10-06: Vue 3.6 release candidate in web. Reason: the design needs 3.6 features; pinned in the lockfile.
- 2026-10-06: TypeScript 6 only for `vue-tsc` in web; everything else uses TypeScript 7. Reason: vue-tsc does not support 7 yet.
- 2026-10-06: Passwords hashed with scrypt, not argon2. Reason: scrypt ships in `node:crypto`, no native dependency.
- 2026-10-06: Refresh token reuse has a 20 s grace window (`REFRESH_REUSE_GRACE_MS`). Reason: two tabs refreshing at once would otherwise revoke the family and log the user out.
- 2026-10-06: The last writer of a work entry becomes its author and confirmation is cleared. Reason: the other party always has something to confirm after any change.
- 2026-10-06: Playwright runs under node, not bun. Reason: Playwright crashes under bun.
